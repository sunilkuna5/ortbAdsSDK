# AdSDK Documentation

Welcome to the AdSDK! This SDK allows you to integrate various ad formats into your Android application.

This documentation provides all the information you need to get started, from initial setup to implementing specific ad types and understanding advanced features.

## Table of Contents

-   **[Getting Started](./GettingStarted.md)**: Prerequisites, installation, permissions, and SDK initialization.
-   **[Banner Ads](./BannerAds.md)**: Learn how to integrate and display banner ads.
-   **[Interstitial Ads](./InterstitialAds.md)**: Integrate full-screen interstitial ads.
-   **[Native Ads](./NativeAds.md)**: Display customizable native ad assets within your app's UI.
-   **[MRAID Support](./MRAID.md)**: Information on MRAID (Mobile Rich Media Ad Interface Definitions) compatibility.
-   **[Testing Guidelines](./Testing.md)**: How to use test mode and test ad unit IDs.
-   **[Error Codes](./ErrorCodes.md)**: A reference for common error codes returned by the SDK.

## API Reference

Full API documentation (KDocs) is generated by Dokka and can be found in the `build/AdSDK/dokka/html` directory after running the `./gradlew AdSDK:dokkaHtml` task. (Note: This step might require local execution if the sandbox environment cannot generate it).

We recommend starting with the [Getting Started](./GettingStarted.md) guide. If you encounter any issues, please refer to the [Error Codes](./ErrorCodes.md) page or consult the API reference.
